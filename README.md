# Система анализа и прогнозирования отклика на интернет-рекламу

Программный комплекс для многомерного анализа поведения аудитории (**OLAP**) и прогнозирования вероятности клика пользователя по рекламному баннеру (`Clicked on Ad`) с помощью моделей машинного обучения.

Проект включает единое ядро на **Python** и два клиентских интерфейса, синхронизированных через общую базу данных **SQLite3**:
* **Desktop-приложение** на базе `PySide6` (Qt 6);
* **Telegram-бот** на базе `aiogram 3` с поддержкой машины состояний (FSM).

---

## Основные возможности

* **Работа с данными:** загрузка CSV-датасетов, очистка неинформативных признаков, извлечение временны́х компонентов (`Month`, `DayOfWeek`, `Hour`), дискретизация возраста на группы (`Age_Group`), пакетное прогнозирование и экспорт результатов.
* **Интерактивный OLAP-анализ:** построение многомерных сводных таблиц по произвольным измерениям, мерам и функциям агрегации (`mean`, `count`, `sum`, `max`, `min`), фильтрация по полу и генерация случайных срезов.
* **Машинное обучение:** индивидуальное и пакетное прогнозирование на базе трёх пайплайнов (`StandardScaler` + классификатор):
  * Логистическая регрессия (`LogisticRegression`);
  * Дерево решений (`DecisionTreeClassifier`);
  * Многослойный перцептрон (`MLPClassifier`).
* **Переобучение моделей:** обновление весов всех трёх моделей и пересчёт метрик качества (`Accuracy`, `Precision`, `Recall`, `F1-score`, `ROC-AUC`) прямо из интерфейса на актуальных данных.
* **Визуализация:** сравнительные столбчатые диаграммы метрик, матрицы ошибок (Confusion Matrix) и тепловые карты OLAP-кубов (в интерфейсе Qt и в виде изображений в Telegram).
* **Единый журнал истории:** сохранение всех запросов из Desktop-приложения и Telegram-бота в общую БД `history.db` с фильтрацией по источнику.

## Технологический стек

* **Язык:** Python 3.14
* **Машинное обучение и анализ данных:** `scikit-learn`, `pandas`, `numpy`, `joblib`
* **Визуализация:** `matplotlib`, `seaborn`
* **Desktop GUI:** `PySide6`
* **Telegram Bot:** `aiogram 3`, `python-dotenv`
* **База данных:** `SQLite3`

## Установка и запуск

1. Скачайте или склонируйте репозиторий и перейдите в папку с курсовой работой:
   ```bash
   git clone https://github.com
   cd Python/course
   ```

2. Установите необходимые библиотеки (если они ещё не установлены):
   ```bash
   pip install PySide6 aiogram pandas numpy scikit-learn matplotlib seaborn joblib python-dotenv
   ```

3. **Запуск Desktop-приложения:**
   ```bash
   python desktop_app/main.py
   ```

4. **Запуск Telegram-бота:**
   Создайте в папке `course/` файл `.env` с токеном вашего бота (`BOT_TOKEN=ваш_токен`) и выполните:
   ```bash
   python bot/main.py
   ```

## Команды Telegram-бота

* `/start` — главное меню бота
* `/predict` — пошаговый расчёт вероятности клика по 8 параметрам пользователя
* `/olap` — интерактивное построение OLAP-среза и тепловой карты
* `/metrics` — вывод метрик качества обученных моделей
* `/charts` — сравнительная диаграмма метрик моделей
* `/history` — просмотр последних 5 прогнозов из общей базы данных
* `/back` — прерывание текущего сценария и возврат в главное меню
